# APEX MOTORWORKS — Инженерный автосервис (3D Dodge Challenger SRT Hellcat)

Демонстрационный веб-сайт современного автомобильного техцентра, построенный на **React + TypeScript + Vite + Three.js + GSAP ScrollTrigger**.

---

## Ключевые особенности

1. **Реальная 3D-модель Dodge Challenger SRT Hellcat (`public/models/dodge_challenger.glb`)**:
   - Интегрирована детализированная 3D-модель с раздельными колёсными дисками, шинами с картой нормалей протектора, шестипоршневыми суппортами Brembo, перфорированными роторами, решёткой радиатора, четырёхконтурной оптикой Air-Catcher и задним фонарём.
   - Упакована в единый бинарный `.glb` (1.99 МБ) для быстрой загрузки одним запросом и полной совместимости с подпапкой репозитория на GitHub Pages (`/service3/`).
   - Полная информация об авторе и лицензии зафиксирована в [`ASSET_CREDITS.md`](./ASSET_CREDITS.md).
2. **Семистадийная скролл-хореография камеры (Three.js + GSAP ScrollTrigger)**:
   - Единый WebGL-контекст с корректной очисткой памяти (`dispose`), адаптацией угла обзора под вертикальные экраны смартфонов, поддержкой `prefers-reduced-motion` и резервным состоянием при отсутствии WebGL.
3. **6-секционная структура сайта**:
   - **01 · Hero & 3D Showcase** (`BUILT TO PERFORM`, интерактивная студия Dodge Challenger SRT Hellcat, переключение заводских оттенков кузова).
   - **02 · Expertise** (Диагностика, Техническое обслуживание, Тормозная система, Обслуживание двигателя).
   - **03 · Engineering** (Инженерная метрология, допуски и устранение первопричин неисправностей).
   - **04 · Workshop** (Специализированные посты, приборная база и стандарты работы).
   - **05 · Process** (3 прозрачных этапа: Запись, Диагностика, Согласование работ).
   - **06 · Contact** (Контактные данные и форма предварительной записи с валидацией).

---

## Локальный запуск и сборка

```bash
# Установка зависимостей
npm install

# Запуск локального сервера разработки (порт 3000)
npm run dev

# Проверка типов TypeScript
npm run lint

# Production-сборка (формирует папки dist/ и docs/ для GitHub Pages)
npm run build
```
